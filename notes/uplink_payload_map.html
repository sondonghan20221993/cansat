Uplink Payload Map

UP2 프레임의 payload 구간(offset 7 ~ 7+plen)을 command_class 별로 펼친 바이트 맵. 프레임 껍데기(DL2/UP2/ACK2)는 lora_frame_map.html 참고. 필드에 커서를 올리면 판독창에 형식·오프셋·검증 규칙이 표시됩니다.

CONFIG · ROUTE_UPDATE · VIEWPOINT · RECOVERY · MODE · DIAGNOSTIC · COUNTER_MGMT · FLIGHT_MODE
오프셋은 payload 시작(UP2 offset 7) 기준입니다. 셀 폭은 바이트 수에 비례하며, 클릭하면 판독이 고정됩니다.

payload가 놓이는 자리

UP2 · 지상 → 기체

아래 모든 맵의 offset 0 = UP2 프레임 offset 7. plen은 u8이지만 기체는 UPLINK_APP_MAX_PAYLOAD_LENGTH = 196B까지만 수용합니다. class 검증 → 길이 검증 → proxy CRC 검증 순으로 통과해야 payload 파싱에 진입합니다.
