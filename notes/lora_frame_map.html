v1 레거시 (ASCII 텍스트)

참조 · 공존 이행용

첫 바이트가 magic(0xD2/0xB2/0xA2)이 아니면 수신 파서는 v1 텍스트로 분기합니다. hex 인코딩·개행 종단 방식.

DL v1F,<ts>,<roll>,…,<crc16>\n / S,<…>\n — FC/SH 상태 텍스트 라인
UP v1UP,<version>,<class>,<seq>,<flags>,<payload_hex>,<crc16>\n
ACK v1ACK,<seq>\n — CRC 없음 (v2 ACK2가 CRC 추가)
레전드 색상 = 필드 기능 그룹. 확장 블록은 빗금 배경으로 구분되며 flags 비트로 첨부 여부가 결정됩니다.
DL2 기본 50B (에어타임 ~21ms) · +SysTime 8B · +waypoint 페이지 28B. 확장 첨부 시 tail(uplink_last_seq/boot_count)과 CRC가 뒤로 밀립니다.
