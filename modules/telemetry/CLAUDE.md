# 작업 규칙

## 파일 작업 권한
- 작업 디렉토리 내부 파일 수정: 승인 없이 가능
- 작업 디렉토리 내부라도 파일/폴더 삭제: 사용자 승인 필요
- 작업 디렉토리 밖 파일 수정: 사용자 승인 필요
- 새 파일/폴더 생성: 작업 디렉토리 내부만 허용
- 삭제 명령 항상 승인 필요: `rm`, `rmdir`, `git clean`, 대량 이동, 덮어쓰기성 삭제 포함

## 명령 실행
- 안전 명령 바로 실행: `test`, `build`, `grep`, `cat`, `ls`, `find`, `git diff`, `git status`
- 위험 명령: 실행 전 한 줄 요약 후 승인 요청

## 답변 형식
- 명사구·키워드 중심, 최소 토큰
- 장황한 설명·배경·예시 금지
- 불필요한 확인 질문 금지
- 파일 수정 후 보고: 변경 요약 + 검증 결과만
